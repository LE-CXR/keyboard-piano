# 键盘钢琴

浏览器里的迷你钢琴：键盘 / 鼠标 / 触屏演奏，多音色、节拍器、录音回放。

## 在线

https://le-cxr.github.io/keyboard-piano/

## 本地

直接打开 `index.html`，或：

```bash
python3 -m http.server 8755
```

访问 http://127.0.0.1:8755/

## 快捷键

- 三排键位：`Z–M` / `A–K` / `Q–I`
- `↑` `↓` 八度 · `[` `]` 模式 · `0–9` 音色

## 结构

- `index.html` 页面壳
- `css/app.css` 样式（暖纸 / 墨夜 / 赤陶 / 海雾 / 余烬）
- `js/boot.js` 主题预载
- `js/app.js` 音频与交互
